# Glossary

Terms used in WindSight, the API, and the UI.

| Term | Meaning in this project |
| --- | --- |
| **Actual** | A half-hourly national wind generation reading from Elexon `FUELHH`, in MW. |
| **Forecast** | An hourly national wind generation value from Elexon `WINDFOR`. |
| **Vintage** | One forecast publish event. The same delivery hour can have several vintages with different `publishTime` values. |
| **Gate closure** | The assumed decision cut-off: 11:00 `Europe/London` on the day before delivery. In January this is 11:00 GMT. |
| **Delivery day** | The day whose wind generation is being forecast or measured. |
| **Settlement period** | A half-hour slot in the GB settlement day. There are 48 in January. |
| **Decision point** | An hourly delivery hour with both a pre-gate forecast and an actual. The actual is the mean of the two half-hour readings. |
| **Pre-gate vintage** | The latest forecast publish for a delivery hour whose `publishTime` is at or before gate closure. |
| **Lead time** | Delivery hour minus forecast publish time, in hours. |
| **Forecast error** | Forecast minus actual, in MW. Positive means over-forecast; negative means under-forecast (a shortfall). |
| **MAE** | Mean absolute error across hourly decision points. |
| **RMSE** | Root mean squared error; penalises large misses. |
| **Bias** | Mean signed error. A positive bias is a persistent over-forecast. |
| **nMAE** | MAE divided by mean actual generation, as a percentage. |
| **P90 absolute error** | The 90th percentile of absolute error. Nine in ten hourly misses are at or below it. |
| **P90 shortfall** | The 90th percentile of positive error only. The reserve side of the distribution. |
| **Shortfall buffer** | The MW amount added to a forecast to cover the P90 over-forecast. Calculated as `max(0, q90)` for the forecast-level bucket. |
| **Within ±1 GW** | Share of hourly points with absolute error at or below 1,000 MW. |
| **Coverage** | Matched decision points divided by the expected 24 per delivery day. |
| **Forecast level** | A bucket based on the forecast MW value: 0–5, 5–10, 10–15, 15–20, 20–25, 25+ GW. |
| **Uncertainty band** | The empirical P10–P90 signed-error range for a forecast level, drawn on the decision chart. |
| **Leave-one-day-out** | For a selected delivery day, the band is fitted on the other days in the month so it is not fitted on the day being shown. |
| **Snapshot** | The committed SQLite database at `backend/data/windsight.db`, generated by `python -m app.ingest`. |
| **Energy (GWh)** | Sum of hourly MW divided by 1,000. The label reflects hourly decision points, not half-hourly settlement energy. |
| **Vintage point** | One (delivery hour, publish time) pair used in the lead-time accuracy view. The month has 8,432. |
